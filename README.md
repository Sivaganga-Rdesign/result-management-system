# 🎓 Result Management System

A frontend-based Result Management System built using React. This application allows users to manage and view student results with a clean and responsive interface.

🔗 Live Demo: https://joy-result-nexus.lovable.app

---

## 🚀 Features

* 📊 Add and manage student results
* ✏️ Edit and delete records
* 💾 Data stored using browser localStorage
* ⚡ Fast and responsive UI
* 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

* ⚛️ React (Frontend)
* ⚡ Vite (Build Tool)
* 🎨 Tailwind CSS (Styling)
* 💾 localStorage (Data Storage)

---

## 📁 Project Structure

```
├── public/          # Static assets

```

---

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/your-username/joy-result-nexus.git
```

2. Navigate to folder:

```
cd joy-result-nexus
```

3. Install dependencies:

```
npm install
```

4. Run the project:

```
npm run dev
```

---

## ⚠️ Limitations

* No backend/database
* Data is not stored permanently (clears on browser reset)
* No authentication system
